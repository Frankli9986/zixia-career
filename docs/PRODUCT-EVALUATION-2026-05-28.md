## 二、创意性（22/40）

### 优势

1. **概念立意好**：「自洽」这个名字有哲学感，切中了应届生「不知道选择是否适合自己」的核心焦虑，定位清晰。
2. **内心委员会创意突出**：8个拟人化声音的设计非常有趣，在路演和Demo场景中有很高的记忆点和戏剧性，是差异化核心。
3. **反焦虑叙事有价值**：强调「没有最优路径，只有最适合你的」，与市面上所有职业测试形成明确区分——去排名化、不给用户贴标签。
4. **12周沉浸模拟的形式**：比传统测试（做完看报告就走）更有参与感和探索深度，模拟器形态本身是创新的。

### 劣势

1. **核心交互太轻**：说是「模拟器」，本质还是 slider 调参数 + 选项点击，没有真正模拟职场决策的复杂度和紧迫感。
2. **缺少「意外感」**：用户做完 onboarding 大概能猜到结局，没有给到「原来我这类人还会这样想」的认知冲击。
3. **与职业规划工具同质化**：目前的产品逻辑接近「简历版 MBTI」，用户可能觉得「我花3分钟测这个，不如直接用北森/MBTI」。

### 具体问题

| # | 问题 | 优先级 |
|---|------|--------|
| C1 | 产品定位模糊：到底是「职业测评工具」还是「沉浸式叙事游戏」？ | P1 |
| C2 | 内心委员会只有文案展示，没有与用户选择产生实质互动 | P1 |
| C3 | 结局推荐内容单薄，只有能力肯定，缺乏具体可操作的职业方向指引 | P2 |

## 三、技术应用（14/30）

### 优势

1. **纯前端架构简洁**：HTML/CSS/JS 无依赖，适合黑客松快速原型和 Vercel 部署，技术选型合理。
2. **localStorage 数据流设计思路对**：在有限场景下用 localStorage 做状态持久化是合适的。
3. **Canvas 雷达图**：onboarding.html 中的雷达图用 Canvas 自绘，技术实现没问题。

### 劣势

1. **DeepSeek API 完全未接入**：`simulateParsing()` 是纯 Mock 数据，简历上传后没有任何 AI 解析发生。
2. **simulator.html 和 onboarding.html 的参数体系不一致**：onboarding 用 `PARAMS[n].key`，simulator 用 `PARAMS[n].id`，导致 `restoreProfile()` 函数体是空壳。
3. **simulator.html 完全独立实现了自己的样式**：内联 `<style>` 而没用 `styles.css`，两个页面的设计系统没有对齐。

### 具体问题

| # | 问题 | 优先级 |
|---|------|--------|
| T1 | `restoreProfile()` 是空壳，Onboarding 过来的画像无法正确恢复 | P0 |
| T2 | DeepSeek API 未接入，简历解析是假的，整个产品故事的核心逻辑断裂 | P0 |
| T3 | 两个 HTML 文件的 PARAMS 参数定义不一致（key vs id） | P0 |
| T4 | simulator.html 的 `startGame()` 函数被截断，逻辑未完成 | P1 |

## 四、完成度（8/15）

### 优势

1. **核心路径基本打通**：上传简历 → 画像微调 → 雷达图确认 → Simulator，流程完整。
2. **有 UI 状态反馈**：Loading 页有 Agent Chain 动画，Toast 提示，分步引导。
3. **内心委员会有完整文案**：8个委员的名称和描述都写好了，不是占位符。

### 劣势

1. **Simulator 游戏逻辑不完整**：只有 2 个事件节点（after_week_3 / after_week_6），12 周模拟只走了 6 周。
2. **结局页面数据未填充**：Ending 页面有结构但内容单薄，三项内容都是占位框架。
3. **印记系统（Imprint）有 UI 无逻辑**：弹窗样式做好了，但印记如何获得、如何影响结局，逻辑未实现。

### 具体问题

| # | 问题 | 优先级 |
|---|------|--------|
| F1 | Simulator 只有 2 个分支事件，12 周只走了一半 | P1 |
| F2 | Ending 页面的三项内容无真实计算逻辑 | P1 |
| F3 | Imprint 获取和展示逻辑缺失 | P2 |

## 五、商业潜力（6/15）

### 优势

1. **目标用户清晰**：应届生，1200万市场规模，需求真实存在。
2. **使用场景存在**：校招季前、offer 比较时、毕业前迷茫期。
3. **反焦虑定位有传播潜力**：「没有最优路径」这个 slogan 在社交媒体上有话题性。

### 劣势

1. **商业模式不清晰**：是免费工具引流 + 付费职业咨询？还是 B 端 HR 服务？目前没有设计。
2. **护城河极低**：任何有 LLM API 的人都可以 copy 这个产品，技术壁垒几乎为零。
3. **用户留存路径缺失**：用户做完一次模拟后，没有理由再回来。

### 具体问题

| # | 问题 | 优先级 |
|---|------|--------|
| B1 | 没有商业模式设计，黑客松之后如何可持续？ | P1 |
| B2 | 内容库太浅——只有 2 个事件、1 种结局框架，无法支撑用户多次使用 | P1 |

## 七、改进建议

### 🔥 Phase 0（黑客松前 24h 必须修）

1. **统一 PARAMS 定义，修复 `restoreProfile()`**
   - 两边都用 `key` 作为唯一标识
   - `restoreProfile()` 补充：恢复滑块值 + 高亮委员会 chip + 显示用户名
   - 验收：做完 Onboarding，进 Simulator，8 个滑块值完全一致

2. **快速替换 DeepSeek API——用 8 题问卷代替**
   - 用户答 8 道选择题（每题对应 1 个维度）
   - 无网络依赖，可离线演示
   - 工作量：2-3h

### 🔥 Phase 1（黑客松展示前完成）

3. **补全 Simulator 事件链**
   - 至少 4 个事件节点（周3/6/9/12）
   - 每个事件有场景描述 + 内心委员会声音 + 2-3 个选项

4. **实现结局计算引擎**
   - 基于 12 周的选择，生成「你的职场风格总结」
   - 提供 3-5 个具体职业方向建议

### 📅 Phase 2（赛后迭代）

5. **内心委员会与用户选择的实质联动**
   - 选择前：委员会辩论（每个委员表态）
   - 选择后：显示哪个委员「赢了」

6. **设计社交分享机制**
   - 用户完成后生成「你的职场自画像」卡片（可分享到朋友圈/小红书）

7. **商业模式设计**
   - 短期：免费工具引流，付费解锁「深度结局分析」
   - 长期：企业端 B2B（校招生适配度测评工具）

## 八、最终评审结论

**评分：50/100（D 档）**

「自洽」的核心创意（内心委员会 + 沉浸式模拟 + 反焦虑叙事）有真正的产品灵魂，是本次黑客松中概念最独特的作品之一。但**概念领先，执行落后**——核心 P0 问题让产品在实际演示时处于半可用状态。

**黑客松现场建议：**
- 全程不离线演示（用 8 题问卷替代 API）
- 路演前准备好 2-3 个「结局示例」，展示不同画像用户会得到的不同结果
- 内心委员会是最大的亮点，围绕它设计 60 秒 Demo 叙事

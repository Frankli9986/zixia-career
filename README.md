# 自洽

> **没有最优路径，只有最适合你的自己**

---

## 项目简介

「自洽」是一个帮助应届生在**低风险模拟环境**中发现自身职业偏好的 AI 产品。

2026 年，中国应届生预计超过 **1200 万**。绝大多数人面临同一个困境：

> *"我有一个模糊的方向，但我不知道这个选择是否真的适合我。"*

---

## 核心流程

| 步骤 | 说明 |
|------|------|
| **1. 上传简历** | DeepSeek API 解析简历 |
| **2. AI 生成画像** | 8 维职场参数 |
| **3. 职场模拟器** | 沉浸式 12 周职场剧情 |
| **4. 结局推荐** | 能力肯定 + 职业方向 |

## 核心亮点

- **沉浸式模拟**：在职场剧情中做真实选择
- **内心委员会**：8 个"人格"在你脑子里辩论
- **去排名化**：没有最优路径，只有最适合你的
- **反焦虑设计**：每个方向都有它的价值
